
# Hexaware Starter Project

## About
A simple full-stack starter project with a frontend
built using HTML, CSS, and JavaScript, and a backend
built using Node.js and Express.

## Project Structure

hexaware-starter-project/
|
|-- backend/
|   |-- server.js
|   |-- package.json
|
|-- frontend/
|   |-- index.html
|   |-- style.css
|   |-- script.js
|
|-- README.md
|-- .gitignore

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Git and GitHub

## Features

- Responsive frontend layout
- Express backend server
- Backend health-check API
- Frontend and backend communication

## Installation

1. Clone the repository.
2. Navigate to the backend folder.
3. Install dependencies:

   npm install

4. Start the backend:

   npm start

5. Open frontend/index.html in your browser.

## API Endpoint

GET /api/health

Returns the backend server status.
